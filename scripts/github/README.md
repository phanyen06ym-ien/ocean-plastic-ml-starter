# scripts/github — lưu trữ

Nội dung issue và PR dùng để tạo backlog Sprint 1–3 trên GitHub (`setup_sprints.py`). Đây là **bản nháp lưu trữ**: một số file được nhắc tới (ví dụ `docs/experiment_plan.md`, `docs/demo_spec.md`) chưa từng được tạo, và ADR nằm ở [`docs/adr/`](../../docs/adr/). Trạng thái thật của công việc xem README mục 1 và trên GitHub Issues.
